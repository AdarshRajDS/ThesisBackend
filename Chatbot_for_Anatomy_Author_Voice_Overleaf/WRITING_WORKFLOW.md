# Thesis Writing Workflow

## Four-stage workflow per chapter

1. **Outline and claim map**: sections, paragraph logic, target word counts, overlap risks.
2. **Evidence map**: literature, code, raw result, screenshot, and missing evidence for each claim.
3. **Section-by-section drafting**: never request a full 15-page chapter in one step.
4. **Audit**: reference verification, implementation consistency, result traceability, overstatement check.

## Evidence hierarchy

1. Frozen repository and code for implementation facts.
2. Raw final evaluation data for numerical claims.
3. Project documents for architecture history and supervisor requirements.
4. Peer-reviewed research for scientific claims.
5. Official specifications for technical protocol and framework behaviour.

## Chapter completion gates

- Chapter 4 requires concrete failure and correction evidence.
- Chapter 5 requires a frozen commit and verified runtime wiring.
- Chapter 6 requires fixed datasets, metrics, and rubrics.
- Chapter 7 requires archived raw outputs and completed result tables.
- Chapter 8 must introduce no new evidence.
